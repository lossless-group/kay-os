# Specs

* [Agentic Email Superpowers](Agentic-Email-Superpowers.md) - The 2025 idea of an inbox run by AI agents, written up after it became kay-os: archive first, agents second.
* [Attachments as First-Class Mail — Find Any Document Ever Sent to Me, by Name, by Words, or by Meaning](Attachments-as-First-Class-Mail.md) - Twenty years of decks, term sheets, contracts and invoices are already on disk and almost none of it is findable. This spec turns every attachment into something an agent can list, open, read, and search, without adding a single server.
* [Mail Connector for the Claude App — Search and Open My Mail From the Phone, Signed In as Me and Nobody Else](Mail-Connector-for-the-Claude-App.md) - One custom connector in the Claude app lets Claude search the mail archive, read a message, and hand over an attachment, from any device. The login is the whole security story, so this spec settles it before any code.
