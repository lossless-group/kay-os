# Explorations

* [Customizing Hermes Agent through API — Making a Hosted Hermes Mine](Customizing-Hermes-Agent-through-API.md) - Hermes already speaks the same skill standard we do. The work is wiring our skills in, our accounts on, and its own skills back out where we can edit them.
* [Using Cloudflare Artifacts as Knowledge Graph — One Git Record Every Agent Can Reach](Using-Cloudflare-Artifacts-as-Knowledge-Graph.md) - Hermes can pull from Cloudflare Artifacts: it's plain git. Artifacts isn't a graph itself, though. It's the record a graph is built from, with history, undo, and a repo per colony member.
* [Email Repository and Agent Harness — One Archive of Every Inbox, and the Agents That Work It](Email-Repository-and-Agent-Harness.md) - kaymail already pulls whole mailboxes to disk. The next step is a permanent home for them, more accounts, and agents that mine, triage and sync contacts from the archive.
* [A Gateway Between Agents and My Accounts — Letting Hermes In Without Handing It the Keys](A-Gateway-Between-Agents-and-My-Accounts.md) - I don't trust Hermes Agent with my email, CRM or calendar yet. kay-os could sit in between: it holds the accounts, and agents get only what it lets through.
